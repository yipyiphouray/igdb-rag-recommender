# Recommend Me Page UI Improvement Plan

This file consolidates the Recommend Me page UI improvement versions into one implementation history. Each section summarizes the intent of that version without preserving the original draft wording.

## V1

- Apply the final website visual style to the Recommend Me page.
- Use the main page title `Recommend Me_`.
- Use clear user-facing copy explaining that the page asks questions and returns matching games.
- Convert the page from a filter-like form into a sequential wizard.
- Include Back, Next, Reset, and final review behavior.
- Use option grids instead of dropdowns for wizard questions.
- Keep large option lists compact and scrollable.
- Add a visually styled loading state after generation.
- Remove technical recommendation-mode details from the user-facing page.
- Rewrite recommendation explanations in plain language.

## V2

- Remove overly rounded styling so the page better matches the sharp website style.
- Move wizard step navigation to the left side.
- Sort or prioritize platform options for easier selection.
- Make expandable text areas and wizard controls visually uniform.
- Show numeric playtime ranges in preference labels.
- Make the Number of Results input visually align with the rest of the controls.
- Add a loading bar.
- Open recommendation game details in a new tab so users do not lose their result list.
- Convert score values into horizontal bar visuals.
- Emphasize Overall Fit with orange while keeping secondary scores black and white.

## V3

- Match the page header style, sizing, and spacing to the other website pages.
- Sort platforms alphabetically.
- Align the Mood Words and Playstyle text boxes.
- Make recommendation score bars larger and use the remaining card space better.
- Increase score percentage visibility.

## V4

- Replace the wizard one-liner with a stronger and more inspiring line.
- Further align the Mood Words and Playstyle text boxes.
- Make score-bar typography match the website’s label style.
- Highlight the `Overall fit` label in orange.
- Style score areas with black backgrounds and white outlines.

## V5

- Remove remaining gray backgrounds from recommendation result areas.
- Ensure score-bar labels use the same monospaced label style as other red/orange labels on the website.

## V6

- Connect the score-bar area to the recommendation card outline instead of creating separate boxes.
- Make score sections equally sized.
- Make the bar-chart area fill the available game-card space.
- Keep score-bar outlines uniform across recommendation cards.

## V7

- Improve the loading state after the user clicks `Generate recommendations`.
- Avoid the feeling that the page is frozen when the progress bar reaches `95%`.
- Add continuous motion during loading.
- Keep the animation aligned with the website style using black, white, orange, and cyberpunk terminal-like motion.

## 3. Visual Direction 

1. Core Concept & Atmosphere
Aesthetic: "High Tech, Low Life." The interface must look like a high-powered hacker terminal, a corporate mainframe, or a futuristic aircraft cockpit from a 1980s or 90s science fiction film. It should feel tactical, slightly dystopian, and heavily digitized.

Vibe: Analog-digital hybrid. It should have the gritty, tactile imperfections of vintage analog hardware (CRT monitors) overlaid with the complex, precise information display of advanced digital systems.

2. Color Palette (Dark Mode High-Contrast)
Backgrounds: Deep Obsidian (#0A0A0A), Midnight Blue (#001021), or Matte Black.

Primary Accents (Glows): Neon Pink (#FF007F), Toxic Green (#39FF14), Cyan/Electric Blue (#00FFFF), or Neon Purple (#BF00FF).

Typography: The standard text should be a high-contrast off-white (#E0E0E0) or the accent color itself to ensure legibility against the dark background.

System Messages: Orange (#FFA500) for warnings, Red (#FF0000) for critical errors.

3. Typography & Character
Headers: Heavy, stylized, geometric sans-serif fonts (e.g., Orbitron, Neuropol).

Secondary/Technical Text: Monospaced fonts exclusively for a "code" feel (e.g., Roboto Mono, Source Code Pro, Space Mono).

Decorative: Use pixel-style fonts sparingly for specific interface elements like labels or numbers to enhance the retro feel.

4. Layout & Structural Elements
Grid System: Visible, precise grid lines separating all main content blocks. Thin, dotted, or dashed lines add to the technical schematic feel.

Containers/Borders: Use Modular Framing. Avoid standard rounded corners. Containers should have angled corners, look like brackets, or be framed by thin, glowing lines that appear modular and interchangeable.

"HUD" Elements: Persisting widgets in the screen corners—like coordinates, time stamps, fake CPU/memory usage bars, or system log readouts—to simulate a military or tactical view.

5. Textures, Effects, & Imperfections
Overlays: A constant, subtle CRT Scanline Effect (line-height manipulation or background image) combined with a gentle screen flicker or static noise texture across the whole screen.

Aberration: Subtle Chromatic Aberration (color splitting) on primary titles and hover effects.

The "Glow": Everything interactive or primary should have a box-shadow or text-shadow that makes it appear to be softly emitting light.

Transitions: Use rapid, digital transitions—like quick glitch flickering, horizontal screen tears, or "digital pixelation" fades—when moving between states.

6. Dynamic Interactions & UX
Boot Sequence: The initial homepage load should simulate a system boot-up sequence, typing out text line-by-line with standard terminal startup copy.

Mouse Interaction: A slight mouse-trailer effect where a small crosshair, digital coordinate, or data packet readout follows the cursor.

Tactile Hover States: Buttons should feel like physical, illuminated toggle switches. On hover, they should change color, glow brighter, or briefly glitch.

Simulated Inputs: Where possible, include elements that look like terminal prompts (C:\> ) even if they are not functional.

# Website Home Page Plan V3


## 1. Updated visual direction

1. Visual Palette (High-Contrast Industrial)
Limit your design to three highly contrasting colors. There are no gradients or soft shadows.

Dominant Background: Pure White (#FFFFFF) or Solid Ink Black (#000000).

Primary Text/Lines: The exact opposite of your background (Solid Black on White, or Solid White on Black).

High-Visibility Accent: Saturated High-Vis Orange (#FF3E00) or Warning Yellow (#FFE600). Used strictly for tiny technical labels, active states, and crosshair elements.

2. Typography Rules
This style relies entirely on contrasting scale—pairing massive headings with microscopic metadata.

Primary Titles & Menu Items: Large, heavy, geometric sans-serif fonts.

System Fonts: Arial Black, Impact, Trebuchet MS.

Google Fonts: Space Grotesk (Bold), Syne, Archivo Black.

Technical Labels & Metadata: Tiny, light, monospaced fonts (9px - 11px) with wide letter spacing.

System Fonts: Courier New, Consolas.

Google Fonts: Space Mono, Roboto Mono.

Typographical Signatures:

All-caps text for all navigation and labels.

Ending main titles with a trailing underscore (e.g., INDEX_, ENTER_).

Preceding menu items with slash-separated database categories (e.g., SEC_01 //).

3. Grid & Layout (Drafting Table Blueprint)
The layout should feel like an architectural blueprint or a technical dossier.

1px Wireframe Borders: Use razor-thin 1px solid lines to divide the screen into rigid, rectangular zones. These lines must run fully to the edges of the browser window.

Asymmetry & Negative Space: Avoid centered elements. Push navigation to the absolute left or right margins, leaving massive blocks of empty space in the center.

Technical Overlays: Scatter subtle, non-functional drafting-table marks in the corners of your containers—like tiny alignment crosses (+), pixel coordinates, or corner brackets.

4. Interactive Behavior & Motion
The site must feel mechanical, snappy, and physical. Avoid slow, organic transitions.

Instant Hover States: On hover, elements should change state instantly (transition: none or transition: 0.05s).

Color Inversion: The primary hover effect is a complete, instant color swap. If a menu block is white with black text, hovering over it instantly flips it to solid black with white text.

Mechanical Reveals: If content fades in, it should do so with a fast, stepped animation (like a camera shutter snapping open) rather than a smooth, soft fade.
